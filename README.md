## 🌱 1. Project Title

Crop Disease Detection Using Deep Learning and Computer Vision

## 📌 2. Problem Statement

Farmers often face difficulties identifying crop diseases at an early stage. Traditional disease identification methods require expert knowledge and time. Incorrect identification may lead to crop damage and reduced agricultural production.

The proposed system uses Deep Learning and Computer Vision to detect plant diseases from leaf images and provide disease classification results.

## 🌾 3. Selected Engineering Scenario

Develop an AI-based system that identifies crop diseases using images of plant leaves.

Expected System Features:

- 📸 Capture or upload a leaf image.
- 🖼️ Preprocess the uploaded image.
- 🧠 Detect diseases using a trained CNN model.
- 🔍 Display the predicted disease name.
- 💡 Provide basic recommendations for disease management.

## ✍️ 4. Base Prompt (Naïve Prompt)

Basic PromptWriting

Suggest a method to detect crop diseases using computer vision.

## 🚀 5. Improved Prompts Using Different Prompting Techniques

### 👨‍💻 Technique 1 – Role-Based Prompting

Writing

Act as an agricultural AI engineer. Explain how to develop a crop disease detection system using computer vision and deep learning. Suggest suitable algorithms, datasets, implementation steps and expected results.

### 🎯 Technique 2 – Zero-Shot Prompting

Writing

Develop a solution for detecting plant diseases from leaf images using deep learning. Explain the complete process, including image preprocessing, disease classification and prediction.

### 📚 Technique 3 – Few-Shot Prompting

Writing

Consider these examples:

Example 1: Input: Healthy tomato leaf image. Output: Healthy.

Example 2: Input: Tomato leaf with yellow spots. Output: Possible early blight.

Now suggest a deep learning-based system that can classify plant leaf images into healthy and diseased categories. Explain the model architecture, training process and prediction steps.

### 🔄 Technique 4 – Step-by-Step Prompting

Writing

Explain how to build a crop disease detection system using computer vision in a structured sequence.

1. Identify the problem.
2. Collect a suitable plant leaf image dataset.
3. Preprocess the images.
4. Select an appropriate CNN architecture.
5. Train and test the model.
6. Evaluate model performance.
7. Develop a user interface.
8. Deploy the system.

Explain each stage with suitable technical details.

### ⚙️ Technique 5 – Constraint-Based Prompting

Writing

Design a crop disease detection system using deep learning with the following constraints:

- Use Python programming.
- Use a CNN-based architecture.
- Use a publicly available plant leaf image dataset.
- The system should classify multiple crop diseases.
- The model should be suitable for deployment on a low-cost computer.
- Include accuracy, precision, recall and F1-score evaluation.
- Explain the implementation in simple engineering terms.

## 🔍 8. Analysis and Observations

1. 📝 Naïve Prompting: Generates simple and general answers.
2. 👨‍💻 Role-Based Prompting: Provides domain-specific suggestions.
3. 🎯 Zero-Shot Prompting: Produces direct solutions without examples.
4. 📚 Few-Shot Prompting: Guides the AI through sample input-output pairs.
5. 🔄 Step-by-Step Prompting: Produces an organized implementation workflow.
6. ⚙️ Constraint-Based Prompting: Generates solutions according to technical requirements.

❓ Does ChatGPT consistently provide better results with improved prompts?

Yes, generally. Improved prompts provide clearer instructions, technical requirements and expected outputs. However, simple prompts can work equally well when the question requires only a short and straightforward answer.

## 🏆 9. Final Selected Prompting Technique

BEST SELECTED TECHNIQUE# ⚙️ Constraint-Based Prompting

Reasons for selection:

- ✅ Provides clear technical requirements.
- ✅ Reduces irrelevant suggestions.
- ✅ Focuses on practical implementation.
- ✅ Includes model evaluation parameters.
- ✅ Helps develop a feasible engineering solution.

## 🧪 11. Engineering Validation

The proposed solution can be validated using the following methods:

| 🔬 Validation parameter | 📝 Validation method |
| --- | --- |
| Dataset quality | Check image labels and image quality. |
| Model accuracy | Evaluate predictions on test images. |

| Recall | Measure correctly detected disease cases. |
